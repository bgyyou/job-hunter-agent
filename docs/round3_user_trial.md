# round-3 真实用户试用指南

> **目的**：v3 round-3 §6 验收最后 1 条「至少 5 个真实用户跑通全流程」的标准操作手册。
> 包含：招募话术 + 反馈表设计 + 数据收集 schema + 收口报告模板。

---

## 1. 招募话术（复制即用）

### 1.1 朋友圈 / 群发版（短）

> 🎯 求职季福利！我做了一个 AI 简历工具，从零生成专业简历 + 自动改写 + 一键导出 Word/PDF。
>
> 5 步流程：填 JD → 填简历 → AI 改写 → 一页纸预览 → 导出。模式 A（保留你的数据） / 模式 B（AI 模板补全）/ auto（自动选） 三种 AI 改写方式。
>
> 找一个你最近在投的岗位试 15 分钟，给我 8 条反馈。**完全免费**（我自己用的 LLM key 不计费）。
>
> 有兴趣回我，我发你链接 + 试用账号。

### 1.2 1v1 私聊版（详）

> 嗨，最近在找工作/实习吗？我做的 AI 简历工具 beta 测试，能根据目标岗位 5 步生成专业简历：
>
> **Step 1**：粘 JD / 上传 JD 图片 / 选行业模板（OCR + RAG 三路）
> **Step 2**：填简历基本信息（带"+"号扩展，默认最小集）
> **Step 3**：AI 改写（模式 A 保留你的数据 / 模式 B 模板补全 / auto 自动切）
> **Step 4**：实时预估一页纸容量 + 瘦身向导（超页给建议）
> **Step 5**：Word / PDF 导出（强制一页，文件名自动 `{姓名}_{岗位}_{公司}.{ext}`）
>
> 我想找 **3-5 个人** 真实跑一次，告诉我哪里卡、哪里惊喜、哪里想加功能。
> 不要求简历漂亮，只看流程是否顺、产物是否可用。
>
> 你只要：
> 1. 准备一份你的真实简历（Markdown / Word / PDF 都行）
> 2. 准备 1-3 个你想投的 JD（粘文本 / 截图 / URL 都行）
> 3. 花 15-30 分钟跑一遍
> 4. 填一份 8 题反馈表（3 分钟）
>
> 试用账号：`http://<你的IP>:8502`，注册随便填邮箱密码（本地测试库，不发邮件）。

## 2. 反馈表设计（8 题，3 分钟填完）

> 试用结束后请把答案粘到这份问卷：

### Q1：你跑到了哪一步？
- [ ] Step 1（JD 输入）
- [ ] Step 2（填简历）
- [ ] Step 3（AI 改写）
- [ ] Step 4（一页纸预览）
- [ ] Step 5（导出）
- [ ] 没跑完，停在第 ___ 步（请写原因）

### Q2：跑完全流程花了多久？
- [ ] < 10 分钟
- [ ] 10-20 分钟
- [ ] 20-30 分钟
- [ ] 30+ 分钟
- 具体时间：___

### Q3：哪一步最卡？（多选）
- [ ] Step 1：JD 输入（OCR 慢 / RAG 不准 / 文本粘贴不方便）
- [ ] Step 2：表单填写（字段太多 / 默认值不合理 / "+" 号逻辑困惑）
- [ ] Step 3：AI 改写（模式 A 改写过头 / 模式 B 编造数据 / auto 选错）
- [ ] Step 4：一页纸预估（不准 / 瘦身建议没用 / 进度条看不到）
- [ ] Step 5：导出（Word 打不开 / PDF 失败 / 文件名乱）
- 其他：___

### Q4：AI 改写质量（满分 5）
| 维度 | 评分 | 备注 |
|---|---|---|
| 保留原数字 / 公司名 | ⭐⭐⭐⭐⭐ | （哪个数字被改了/哪个公司名丢了） |
| 改写自然（不像机器人写的） | ⭐⭐⭐⭐⭐ | （哪段最别扭） |
| 模式 B 不编造具体公司/学校 | ⭐⭐⭐⭐⭐ | （是否看到"字节/阿里/复旦"等具体名） |
| 改写说明（rewrite_reason）有帮 | ⭐⭐⭐⭐⭐ | （说明太啰嗦/太简略） |

### Q5：生成的简历你愿意用吗？
- [ ] 直接用（投出去没问题）
- [ ] 微调后用（哪些地方需要改）
- [ ] 重写一份（哪些地方不行）
- [ ] 完全不用（为什么）

### Q6：哪 1 个功能最惊喜？
（开放回答，1-2 句）

### Q7：哪 1 个功能最想砍？
（开放回答，1-2 句）

### Q8：下一个版本最想要什么？
（开放回答，1-2 句）

## 3. 数据收集 schema

把每条用户反馈落成 JSON 行，存到 `data/round3_feedback.jsonl`（每行一个用户）：

```jsonl
{"user_id": "u01", "submitted_at": "2026-07-13T14:30:00", "q1_step_reached": "Step 5", "q2_time_minutes": 18, "q3_blocked_steps": ["Step 2: 默认 1 段教育 + 1 段工作太少了"], "q4_quality": {"preserve_numbers": 5, "natural_rewrite": 4, "no_fabrication": 5, "rewrite_reason_helpful": 4}, "q5_use_intent": "微调后用", "q5_what_to_fix": ["Step 2 加项目字段默认 1 段"], "q6_surprise": "模式 A 改写后数字保留很准", "q7_cut": "Step 4 进度条可省略", "q8_next": "加一键投递 Boss/猎聘", "raw_notes": "（用户原始原话，可选）"}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `user_id` | str | ✓ | u01-u99 顺序编号 |
| `submitted_at` | ISO datetime | ✓ | 提交时间 |
| `q1_step_reached` | str | ✓ | 跑到第几步 |
| `q2_time_minutes` | int | ✓ | 总耗时 |
| `q3_blocked_steps` | list[str] | ✓ | 卡在哪 |
| `q4_quality` | dict | ✓ | 4 维度 1-5 分 |
| `q5_use_intent` | str | ✓ | 直接用/微调/重写/不用 |
| `q5_what_to_fix` | list[str] | – | 微调/重写时具体改什么 |
| `q6_surprise` | str | ✓ | 最惊喜 |
| `q7_cut` | str | ✓ | 最想砍 |
| `q8_next` | str | ✓ | 下一个版本最想要 |
| `raw_notes` | str | – | 用户原话 |

## 5. 数据合规与隐私

- **不要收集**：真实姓名、手机号、邮箱（除非用户主动填进简历表单，那属于简历内容而非反馈）
- **必须收集**：反馈内容、跑到的步骤、耗时、AI 评分
- **保存位置**：`data/round3_feedback.jsonl`（gitignored）
- **删除**：试用结束后 30 天内可要求删除

---

## 6. 实施步骤

1. **招募**（你来做）：用 §1.1 或 §1.2 话术找 3-5 个朋友
2. **试用**（用户做）：跑全流程 15-30 分钟
3. **反馈**（用户做）：填 §2 八题问卷（3 分钟）
4. **收集**（你或 AI 做）：粘到 `data/round3_feedback.jsonl`
5. **汇总**（AI 做）：跑 `python scripts/aggregate_round3_feedback.py` 生成 §4 模板
6. **报告**（你 + AI 做）：填到 `update_plan.md §8.1` round-3 收口行
